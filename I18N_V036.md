# AcoDyslex V0.3.6 — Interface arabe et anglaise

## Fonctionnement

L’interface démarre en arabe avec `lang="ar"` et `dir="rtl"`. Le sélecteur visible permet de passer à l’anglais, qui applique `lang="en"` et `dir="ltr"`. Le choix est conservé dans `localStorage` sous la clé `acodyslex-ui-language` et reste actif après rechargement.

Le module central [`static/i18n.js`](static/i18n.js) fournit `t(key, params)`, charge les catalogues JSON et traduit les textes statiques ainsi que les messages ajoutés dynamiquement. Les catalogues se trouvent dans :

- [`static/locales/ar.json`](static/locales/ar.json)
- [`static/locales/en.json`](static/locales/en.json)

Les mots, lettres, syllabes, phonèmes et exemples arabes utilisent toujours `lang="ar"` et `dir="rtl"`, y compris dans l’interface anglaise. Les noms de modèles, Meta, Modal, FastAPI et les identifiants techniques restent inchangés.

## Consignes pédagogiques

Les titres, objectifs, instructions, aides et retours des sept familles d’activités sont traduits à partir de clés sémantiques. Les consignes demandent à l’accompagnateur de guider l’enfant. Les identifiants d’exercices, de compétences, les tentatives et les scores ne dépendent pas de la langue choisie.

La traduction couvre aussi :

- les profils et le parcours de quinze mots ;
- les états d’enregistrement, de pause et de passage automatique ;
- l’Analyse Acoustique AI et ses quatre étapes ;
- le bilan et la validation humaine ;
- les sept exercices et l’évaluation par l’accompagnateur ;
- le Laboratoire audio et la classification phonémique détaillée ;
- les messages d’erreur et les confirmations locales.

## Vérifications automatisées

Les tests Playwright vérifient le démarrage en arabe, le changement de langue, la persistance après rechargement, les directions RTL/LTR, les sept traductions d’activités, le maintien du contenu arabe en RTL, le Laboratoire audio, les états de l’analyse et les erreurs. Les tests existants du parcours complet continuent d’utiliser les mêmes API et les mêmes données métier.

## Traductions manquantes

Aucun texte d’interface de premier niveau identifié n’est laissé sans traduction. Les valeurs libres renvoyées par un service externe, les noms propres de modèles et les identifiants techniques sont affichés tels qu’ils sont fournis afin de préserver leur exactitude scientifique.
